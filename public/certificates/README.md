# Folder Tangkapan Layar & Bukti Sertifikat / Lisensi

Folder ini digunakan untuk menyimpan file gambar tangkapan layar (*screenshot*) sertifikat, lisensi, atau bukti kredensial kelulusan Ikhwan Ramadhan.

## Struktur Penamaan Rekomendasi:
- `/certificates/cert-1.jpg` -> Tangkapan layar Sertifikat Full-Stack Web Development & Modern Next.js Architecture
- `/certificates/cert-2.jpg` -> Tangkapan layar Sertifikat Time Series Forecasting & Deep Learning LSTM
- `/certificates/cert-3.jpg` -> Tangkapan layar Sertifikat Relational Database Engineering & ORM Optimization
- `/certificates/cert-4.jpg` -> Tangkapan layar Sertifikat Linux System Administration & Docker Containerization

## Cara Menggunakan:
1. Simpan atau unggah file gambar screenshot (format `.jpg`, `.png`, atau `.webp`) ke dalam folder `/public/certificates/`.
2. Jika file gambar belum diunggah, aplikasi secara otomatis menampilkan kartu pratinjau sertifikat resmi (*high-resolution digital credential fallback*) dengan nomor badge dan segel validasi yang rapi.
