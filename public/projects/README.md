# Folder Gambar Screenshot Proyek

Folder ini (`/public/projects/`) disediakan khusus agar Anda dapat dengan mudah menimpa (*replace/overwrite*) gambar tangkapan layar (screenshot) homepage dari setiap proyek Anda.

Cukup simpan/unggah file screenshot Anda dengan nama file berikut:

1. `smpn24.jpg` (atau `.png`) → Screenshot Website SMP Negeri 24 Padang
2. `ingstore.jpg` (atau `.png`) → Screenshot Ing Store Automotive E-Commerce
3. `monorepo.jpg` (atau `.png`) → Screenshot Fullstack CRM/ERP Monorepo
4. `siklon.jpg` (atau `.png`) → Screenshot Prediksi Siklon Tropis (siklon.streamlit.app)
5. `inventory.jpg` (atau `.png`) → Screenshot Inventory Management System
6. `dockrank.jpg` (atau `.png`) → Screenshot DockRank TF-IDF Document Search
7. `adminblog.jpg` (atau `.png`) → Screenshot Admin Blog Platform Next.js
8. `reactnative.jpg` (atau `.png`) → Screenshot React Native E-Commerce Mobile

Format yang didukung: JPG, PNG, WebP. Jika file belum ditimpa, sistem secara otomatis menggunakan fallback gambar yang tetap rapi.
